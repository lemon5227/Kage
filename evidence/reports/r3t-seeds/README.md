# R3 训练 seed 复现（Kaggle v34–v41，2026-10-27 至 10-31）

回应审稿意见“只有一个训练 seed”：用与原 R3 完全相同的数据（`train.jsonl` sha256 `70d0c442…`，1,677 条）和超参（rank 16、safe 目标、lr 1e-4、2 轮、8,192 上限、420 步），换 seed 1、2 重训。
唯一差别：原 R3（seed 0）在 Colab A100 上 bf16；这两个在 Kaggle T4 上 fp16（T4 的 bf16 是软件模拟，约 15 倍慢），注意力按 1,024 个 query 分块精确计算（CPU 上与 SDPA 前向/反向一致）以在 16 GB 内放下 8,192。

- 训练：v39（seed 2 到 384 步暂停；seed 1 在 140 步被主机内存 SIGKILL）→ v40 从检查点续完。日志 `v39/`、`v40/`。适配器 GGUF sha256：seed 1 `39d063ce…`，seed 2 `d2d167da…`（适配器本身在私有存储）。
- 评测：v41（`adapter-eval r3t1 r3t2`），与 R3 同协议，每个适配器文件/网页各 3 次，同会话原模型 1 次锚点，通用 30 题。原始结果 `evidence/kaggle/v41-results.tar.gz`。
- 分析：`python3 evidence/reports/r3t-seeds/analyze.py` → `analysis.json`（与论文 verify.py 同一套题级精确 sign-flip）。

## 题级检验（升/降/平，精确双侧 p，nominal）
- seed 1 vs 同会话锚点：学过 +0.46（13/2/9，p=121/16384）；留出 −0.42（0/5/7，p=1/16）。
- seed 2 vs 同会话锚点：学过 +0.39（12/3/9，p=79/8192）；留出 −0.36（2/5/5，p=1/16）。
- 对 v26 三次原模型：留出 seed 1 p=1/32、seed 2 p=1/16；两 seed 平均：学过 15/1/8 p=27/32768，留出 2/6/4 p=5/128。
- 与 seed 0 比：学过 −0.01（p=1）、−0.08（p=59/128）；留出 −0.03、+0.03（p=1）——没有可检出的差别。
- 会话漂移：v41 锚点与 v26 原模型总数完全相同（10/24 vs 30/72；5/12 vs 15/36），题级 +0.00。
- 网页学过：+0.32（p=9/256）、+0.35（p=11/512）。

## 结论
“学过的族大幅提升、没学过的写代码族塌掉”在三个训练 seed 上都出现，幅度一致；不是一次训练的偶然。局限：一份数据、一个模型、一组超参；seed 1/2 与 seed 0 精度和硬件不同，seed 与精度没有分开。
