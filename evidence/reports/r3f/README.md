# R3f：自蒸馏代码回放（采集 v46，2026-11-01）

**问题**：R3 学过的题大涨、留出的写代码题塌（R3g 已排除“读回习惯”这个解释，见 `../r3g/README.md`）。R3 的回放数据里没有写代码样本。如果回放用原学生自己在**其它**编程题上写对并通过检查的代码，能不能保住写代码能力？

**采集**（`kaggle_phase` = `r3f-collect`，v46；v45 被误取消）：4 个只用于回放的编程族（`core/evolution/code_tasks.py`：后缀表达式求值、游程编码、网格旋转、版本号排序；不在学过/留出/评测集中），原学生（不加适配器），无引导，温度 0.6，每族 24 个练习 seed（13000–13023）× 4 次，只收严格通过检查器的轨迹，每族上限 150 条。

| 族 | 通过 / 尝试 | 收下的样本 |
|---|---|---|
| rpn_eval | 88/96 | 150（上限，丢 248） |
| run_length | 90/96 | 150（上限，丢 227） |
| grid_rotate | **0/96** | 0 |
| version_sort | 14/96 | 63 |
| 合计 | 192/384 | **363** |

- grid_rotate 全部失败是学生能力，不是检查器问题：参考解通过检查器（`tests/test_code_tasks.py`），学生的典型解把顺时针旋转写成了转置、把“空行网格原样返回”写成返回 `[]`。
- 回放数据 `sft-replay.jsonl.gz`（363 行，三族）；R3 数据 + 回放 = 训练 2003 / 验证 260 行（R3 为 1677 / 223）。原始包 `evidence/kaggle/v46-results.tar.gz`，各族统计 `v46/`。
- 训练：`r3t-train f0 f1`（R3 的数据和超参数不变，只加这份回放），两个 seed，约 500 步，T4 预计两个会话。
