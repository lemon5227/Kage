## 结论
- **遗忘修好了**：第一次有 R3 系列版本同时保住两者——学过 57、65/72（≥55），留出 15、18/36（≥12，回到原学生 15/36；R3 为 0–2，R3g 为 5）。只改了一处：回放里加了 363 条原学生自己在**其它**编程题上写对的代码。损伤的是“写对没见过的代码”，回放覆盖这个能力就保住了。
- **但 RSI 第二轮的进入条件还差一项**：读回率仍为 0（回放和 R3 数据里的写文件轨迹都没有读回步骤）。R3g 已经证明读回是训练轨迹形状的副产品、插回数据即可 100% 恢复且不影响其它指标。
- 下一步：**R3fg** = R3f 数据 + R3g 的读回插入（`r3_data.py --readback` 同时作用于回放行），两个 seed，同配方同评测；预期三项同时满足后进入第 2 轮。另需看 f0 的误用题是否复现。
