## 对论文的含义
1. 新题上复现了最强的接口结论（TextEdit 3/18 → 18/18，6/6 题），第二学生同样复现（2/18 → 17/18，6/6 题）。
2. 规则采纳：原稿“规则放任务旁 + 先写计划”的组合在新题上复现（1/30 → 23/30）。拆开后，**主要是位置**：规则在任务旁、不要求计划已到 19/30，对系统提示 6/30 显著；计划在此基础上只再加 4 次（p=7/32）。原稿把作用归于“写计划把规则落到本题”，这一点应改弱。
3. 新的负面发现：同一位置效应也让规则被过度套用（对照题 18/18 → 8/12）。
4. 仍然的边界：单一学生、单一规则族（计算器 1 条规则）、单一会话；题目由开发者写，但写定并提交后才第一次运行。
