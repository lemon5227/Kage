# D5：OpenCLI 接入（网站 → JSON 命令，2026-10-25）

**做法**：OpenCLI 2.0.2（npm 全局 + Chrome Browser Bridge 扩展，用户已装、`opencli doctor` 连通）。`core/tools/opencli_tool.py`：按站点缓存命令目录（名称、读/写、参数），`opencli_read` 只执行 `access: read` 的命令（`download`/`login`/`whoami` 也排除——会写盘或走登录流程），`opencli_write` 注册为 DANGEROUS（执行前由服务端请用户确认）；输出截断（≤10 行、字段 ≤300 字）；空结果提示“可能需要先登录”。
请求点名站点（B站/知乎/小红书/微博/抖音/12306/微信读书/闲鱼/一亩三分地）时，服务端**独立小循环**：只给 `opencli_read` + 该站只读命令清单，本地模型 ≤3 步；排在 Kage 早期的视频/搜索启发式之前。

| 版本 | 结果 |
|---|---|
| 工具 + 命令清单附在请求后，走主循环 | B站 3/3 拿到数据，但 2 条先多跑一次 YouTube 搜索（老“视频”快速通道）；“排行榜第一”“知乎热榜”被老“信息搜索”通道抢走，回答成网页搜索结果（知乎答成了知乎官网简介） |
| **独立小循环（先于老通道）** | **B站 3/3 真实数据**（热门前五、“AI Agent 教程”搜索、排行榜第一）；知乎、小红书如实说明需在 Chrome 登录（未登录：知乎匿名返回空、 小红书 AUTH_REQUIRED）；0 次 YouTube 搜索；使用日志 3 成功 2 失败 |

**待补**：用户在 Chrome 登录知乎、小红书后，各补 3 条读取（任务卡验收）。写操作（评论、关注、发布）只在确认后执行，本阶段不测真实写入。
