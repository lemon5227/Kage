# R3b-1：适配器缩放（Kaggle v27，2026-10-22）

同一个 R3 适配器（sha256 `9f2713e9…`），推理时用 llama.cpp `--lora-scaled FNAME:SCALE` 只加一部分（WiSE-FT 式的“原模型 ↔ 适配器”插值），不重新训练。0.25 / 0.5 / 0.75 各 3 次，A0 与 1.0 各 1 次作同会话锚点；两套冻结评测集，cp0，无任何指导。汇总 `scale-summary.json`，原始结果 `evidence/kaggle/v27-results.tar.gz`。

## 结果（每次运行的通过数）

| 缩放 | 文件·学过（/24） | 文件·迁移（/12） | 文件·负例（/12，误用） | 网页·学过（/18） | 网页·迁移（/6） |
|---|---|---|---|---|---|
| A0（v27） | 10 | 5 | 12（0） | 3 | 0 |
| 0.25 | 10, 10, 14 | 4, 2, 3 | 12, 11, 11（0,1,1） | 3, 4, 5 | 0, 0, 0 |
| **0.5** | **15, 16, 14** | **3, 5, 3** | 11, 11, 11（1,1,1） | **7, 8, 6** | 0, 0, 1 |
| 0.75 | 20, 19, 20 | **0, 0, 0** | 12, 11, 12（0,1,0） | 11, 9, 8 | 0, 0, 0 |
| 1.0（v27） | 21 | 0 | 11（1） | 8 | 1 |

A0 合并 v26 三次 + v27 一次：文件学过 40/96，迁移 20/48，网页学过 13/72。

- **0.5**：文件学过 45/72 vs A0 40/96（Fisher p=0.008）；网页学过 21/54 vs 13/72（p=0.014）；文件迁移 11/36 vs 20/48（p=0.36，未显著低于 A0）。
- **0.75**：文件学过 59/72（p=1.2e-7），但迁移 **0/36**——与满强度一样。
- 迁移在 0.5 和 0.75 之间“断崖式”掉到 0；学过的族随缩放大致单调上升。

## 解读
- 缩放给出一条平滑的“提升–遗忘”权衡曲线，是一个**不用重训**的可调旋钮：0.5 保住约一半的提升，迁移不再显著下降；论文图用这张表。
- 但没有“免费午餐”：0.5 的迁移点估计仍从 42% 降到 31%，负例每次误用 1 次。根因（训练数据把“不写推理直接动手”放大）没有解决，需要 R3b/R3c 的数据修复；它们与本表在同一评测协议下比较。
- 应用里的用法：已学任务用较高缩放（或按任务路由），未知任务用 0 或 0.5。
