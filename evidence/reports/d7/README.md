# D7：决策模型做意图路由（10-26）

每轮先问 Clef 一个选择题“这句话是哪类请求”（同一次调用顺带问日程哪天、邮件要总结还是原文），置信 ≥0.8 走对应处理器；不确定交给本地模型的通用流程；Clef 不可用时退回原来的正则链。处理器只负责取参数（收件人、第几封、应用名…），参数提取不了时发微信用本地模型抽取并核对收件人在原话里。
