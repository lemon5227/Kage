- 网页学过题：对同会话原学生 +0.30（p = 1/64）、+0.32（p = 1/128）。
- 读回之后从不改写：留出题上 fg0 12 次、fg1 29 次读回，**改写 0 次**（原学生、R3f 同样为 0）。读回是“写完看一眼”的轨迹形状，不是“发现错误再修”。
- 误用：`lookalike_readonly-10502` 在 fg1 上 3 次都执行（R3f 是 f0 上 3 次）——同一道题、换了 seed，说明是这道题对 R3 系列数据普遍有吸引力，而非某个 seed 的偶然。

## 结论
- **RSI 第二轮进入条件三项全部满足**：学过 65、63/72（≥55），留出 19、13/36（≥12），读回 >0（约 97%）。读回插入与代码回放互不干扰：学过、留出、网页、通用都与 R3f 无显著差别，读回从 0 恢复到与 R3g 同级。
- 需要带着走的限制：①留出只是回到原学生水平（fg1 13/36 低于同会话锚点，未显著）；②读回只是形式，从未触发修改；③`lookalike_readonly-10502` 误用跨 seed 复现，第 2 轮的负例应覆盖这一类。
