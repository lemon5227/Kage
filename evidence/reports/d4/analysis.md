# D4a：微信只读——截图 + 本地文字识别（2026-10-25）

**为什么不用辅助功能接口**：微信 4.1.13 只暴露 6 个界面节点；设置 `AXManualAccessibility` / `AXEnhancedUserInterface` 被拒（-25205 / -25208）。

**做法**（`core/wechat_reader.py`）：`screencapture -l` 截微信主窗口（被遮挡也能截）→ macOS Vision 文字识别（中英文，本机，不上传）→ 以右对齐的时间列定位会话列表，组装“会话名 / 预览 / 时间”；未读标记看头像右上角的红色（约 (231, 94, 88)），角标里的数字取自同区域的识别结果。截图用完即删。“微信有什么未读消息”走服务端直达。

**验收**（真实账号，一屏 10 个会话；人工看截图标注，截图不入库）
| 项 | 结果 |
|---|---|
| 会话名 | 10/10 |
| 时间 | 10/10 |
| 未读标记（数字角标 + 小红点） | 4/4（修正前 1/4：像素按 BGRA 读，实为 RGBA；且红色的绿分量 94 超过阈值 90） |
| 角标数字 | 腾讯新闻 26 ✓ |
| 免打扰群预览“[10条]” | 未解析成数字（小问题） |

**结论**：只读可行（会话、时间、未读 100%），进入 Kage。局限：只看当前一屏；用户拒绝了测试时让我滚动微信列表的权限，所以没有做多屏测试。

**D4b（发消息）**：需要往微信里模拟键盘输入；测试时的操作权限被用户拒绝，暂停，待用户决定。
