## 架构与本轮纠正

执行主链：PromptBuilder → ModelProvider/Broker → AgenticLoop → ToolExecutor/Registry → 动作/观察 → 独立完成检查。E1/E2/E3复用runner/journal/budget/Promoter，绑定候选版本并记录实际加载证据。

文件技能在独立进程/Docker运行；浏览器Page在活worker内，v2参数化声明式工作流按最新观察解析标签，每个子动作计量，复用E1候选/晋级，以后台/页面读回独立检查。B2.2没有技能调用；R2云、本地dev及新四项设置均已有真实绑定/调用证据，更多迁移与相对raw收益仍待验。

错误新DOM已能送入模型history，浏览器档案setup/反馈投影已适配。原开发示范是学生设置、教师observe+Save的混合来源。新留出云组自然接管3/7成功；原始模型轨迹和未完成记录均保留，不把教师救场写成小模型学会。

## 资源与交接原则

本地负责观察/执行和可完成的决策，复杂任务按预算交廉价云；经验/技能迁移先于权重微调。LocateAnything仅作定位候选，oMLX只在同权重任务对照有收益后替换；Husky不进入队列。历史Colab曾获得T4且会员额度为0，下一次可用性必须重新检查。

原始artifacts在活动worktree，报告/计划入Git；交接时核对路径/hash，不能清理唯一证据副本。每包报告实际执行者、失败、源码/协议/模型版本、预算、层级与限制。总规划只改状态与入口，历史细节放[实验报告](experiments/README.md)，小模型只读取当前包。
