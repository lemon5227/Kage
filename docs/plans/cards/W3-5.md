# W3-5 技能导出为 Agent Skills 格式

- 档位：低　执行者：C 或便宜模型　依赖：W2-1 ✅
- 先读：`core/evolution/skills.py`（manifest 格式）
- 产出：`scripts/export_skills.py`、测试 `tests/test_export_skills.py`

## 行为
`python scripts/export_skills.py --bundle <技能库目录> --out <输出目录>`：对 manifest 里每个技能生成
```
<out>/<skill_id>/SKILL.md      # YAML 头：name, description；正文：参数表、何时使用、何时不要用、来源（教师示范 task_id、验证结果）
<out>/<skill_id>/scripts/skill.py   # 原样复制技能源码 + 一个命令行入口：python skill.py '<json参数>' <工作目录>
```
SKILL.md 正文控制在 60 行内（渐进加载：先只读头部，需要时再读正文和脚本）。

## 测试
用测试里现成的小 bundle 导出，检查文件存在、YAML 头可解析、脚本能在临时目录运行。
