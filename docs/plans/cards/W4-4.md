# W4-4 版本树 + 按后代表现选父（HGM 思路）

- 档位：高　执行者：C（强模型）　依赖：W2-1 ✅
- 先读：Huxley-Gödel Machine 摘要（arXiv 2510.21614）、`core/evolution/recovery_loop.py`（verified 列表、回退）
- 产出：`core/evolution/lineage.py`、`scripts/experiments/lineage_plot.py`、测试 `tests/test_lineage.py`

## 数据
`lineage.jsonl` 每个版本一行：`{id, parent, target, digest, hypothesis, created, validation: {passed, total}, status: active|rejected|retired}`。

## 选父
`select_parent()`：对每个已晋级节点，计算「子树分数」= 它和所有后代 validation 通过率的平均（带拉普拉斯平滑 (k+1)/(n+2)）；按子树分数取最高，平分时取较新的。被拒绝的候选也算入其父的子树（体现「这条路好不好长」）。

## 可视化
`lineage_plot.py` 输出 `tree.svg`：节点颜色 = 状态，标签 = 假设前 20 字 + 通过率。纯 Python 生成 SVG，不依赖 graphviz。

## 测试
构造一棵小树验证子树分数与选父结果；SVG 能生成且节点数正确。
