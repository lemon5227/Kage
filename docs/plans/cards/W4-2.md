# W4-2 技能修复 / 合并 / 停用

- 档位：中　执行者：C　依赖：W4-1
- 先读：`core/evolution/mutator.py`（同 skill_id 会替换旧版本）、`competence.retirement_candidates`
- 产出：`core/evolution/practice.py`（`maintain_library(...)`）、测试

## 规则
1. **修复**：修复队列里同一技能失败 ≥2 次 → 用 Mutator 提出同 skill_id 的新版本，反馈 = 失败任务的公开指令 + 学生实际轨迹 + 「the skill was called and the external check failed」。新版本必须在**这些失败任务**和**该技能之前成功过的 2 个任务**上都通过，才替换；否则保留旧版本。每轮最多修 1 个技能（控费）。
2. **合并**：两个技能描述词重叠 > 0.7 且都 active → 只记录候选，不自动合并（留给人工或 W4-3）。
3. **停用**：`retirement_candidates` 给出的技能从 manifest 移除到 `retired.json`（保留源码与原因），能力自评里状态设为 retired。停用也是新版本，走同样的 digest/回退机制。
4. 所有变更写 `root/library_changes.jsonl`。

## 测试
修复通过/不通过两条路径、停用后技能不再出现在 catalog、变更记录完整。
