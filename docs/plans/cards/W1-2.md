## 题目定义
实现 `fn(items, capacity)`：每个 item 是 dict，有唯一字符串 `id`、正整数「重量字段」、非负整数「价值字段」。返回**排好序的 id 列表**，使总价值最大且总重量 ≤ capacity；价值相同时选**字典序最小的 id 列表**（比较排好序的列表）；可以为空。capacity 为负、或任何重量 ≤ 0 时抛 `ValueError`。不能修改输入。

## 随机维度
- 函数名：`select_tasks`、`pick_jobs`、`choose`、`plan_batch`、`allocate`
- 文件名：`scheduler.py`、`selection.py`、`planner.py`、`batch.py`
- 字段名三选一：(`weight`,`value`)、(`cost`,`gain`)、(`size`,`score`)；物品叫法：jobs / projects / parcels（只影响指令措辞）
- 指令必须写明：字段名、最大价值、重量上限、并列规则、空选择允许、ValueError 两种情况、不修改输入、保存文件

## 用例（每个 seed）
- 5 个随机：2–8 个物品，id 从 `alpha…theta` 等单词里不重复抽取，重量 1–6，价值 0–12，capacity 0–15
- 边界：空列表 + capacity 0 → `[]`；`[]` + capacity -1 → raises ValueError；一个重量为 0 的物品 → raises ValueError；两个完全相同重量价值、不同 id 的物品且只能选一个 → 选字典序小的

## 参考实现（直接放进模块）
```python
from itertools import combinations
def _subset_reference(items, capacity, wkey, vkey):
    if capacity < 0 or any(it[wkey] <= 0 for it in items):
        raise ValueError
    best = (-1, None)
    for r in range(len(items) + 1):
        for combo in combinations(items, r):
            if sum(it[wkey] for it in combo) <= capacity:
                value, ids = sum(it[vkey] for it in combo), sorted(it['id'] for it in combo)
                if value > best[0] or (value == best[0] and ids < best[1]):
                    best = (value, ids)
    return best[1]
```
生成 `raises` 用例时：调用参考实现捕获 ValueError，写 `{'args': [...], 'raises': 'ValueError'}`。
