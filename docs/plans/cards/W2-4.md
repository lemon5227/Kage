# W2-4 A3 轨迹记忆臂

- 档位：中　执行者：C 或中档模型　依赖：W2-1 ✅
- 先读：`scripts/experiments/learning_ablation.py` 的 `DemonstrationChain`（第 26–40 行）、`core/evolution/stream.py`
- 产出：`core/evolution/stream.py`（`ARMS['A3']`、`MemoryStore`、`memory_runner`）、`stream_run.py`、测试 `tests/test_stream_memory_arm.py`

## 做法
1. `ARMS['A3'] = {'learn': 'memory', 'help': 'after_failure'}`。`StreamLearner._learn` 在 `learn == 'memory'` 时不提取技能，而是把**通过外部检查的教师示范**存进 `MemoryStore`。
2. `MemoryStore(root/'memory.jsonl')`：每条 `{family_hint, instruction, rows}`，`rows` 只保留教师轨迹里的 `action`（name、arguments）和 `observation`（success、content 截断到 1500 字），不保存任何 scoring 信息。
3. 检索：A3 学生运行时，按指令与记忆指令的词重叠（小写分词后的 Jaccard）取最相近的 1 条，Jaccard < 0.2 就不注入。**不能用 task['family'] 检索**（运行时 Agent 不知道题目属于哪个族）。
4. `memory_runner(...)`：和 `chain_runner` 一样，但用一个 `DemonstrationChain` 风格的子类，把检索到的示范行放在 history 前面。
5. 注入的示范总长度上限 4000 字符，超过就截断旧的行。

## 测试
- 只读任务的示范（没有写文件）不存
- 检索不看 family、低相似度不注入
- 集成：脚本化学生「看到示范里的 write_file 就照抄参数里的写法」，A3 在第二道同族题上通过
