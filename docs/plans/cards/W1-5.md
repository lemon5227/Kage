# W1-5 F5 文本规范化生成器（family = `text_normalize`，只用于评测）

- 档位：低　执行者：C 或便宜模型　依赖：W1-1 ✅
- 产出：`stream_tasks.py`（`text_normalize`、`_normalize_reference`）、`tests/test_stream_text_normalize.py`

## 题目定义
实现 `fn(text)`：生成 slug。步骤：Unicode 用 `unicodedata.normalize('NFKD', ...)` 后去掉非 ASCII 字符；转小写；把所有非 `[a-z0-9]` 的连续字符替换成一个分隔符；去掉首尾分隔符；如果有长度上限，截断到上限后再去掉末尾分隔符。非字符串输入抛 `TypeError`。

## 随机维度
- 分隔符：`-` 或 `_`；长度上限：None 或 8–24
- 函数名：`slugify`、`make_handle`、`to_key`、`label_id`；文件名：`slugs.py`、`naming.py`、`labels.py`

## 用例
- 5 个随机：混合大小写、空格、标点、带重音字母（`Café Déjà`）
- 边界：`''` → `''`；`'---'` → `''`；`None` → raises TypeError；长度上限正好截在分隔符上

## 参考实现
```python
import re, unicodedata
def _normalize_reference(text, sep, max_len):
    if not isinstance(text, str):
        raise TypeError
    ascii_text = unicodedata.normalize('NFKD', text).encode('ascii', 'ignore').decode()
    slug = re.sub(r'[^a-z0-9]+', sep, ascii_text.lower()).strip(sep)
    if max_len is not None:
        slug = slug[:max_len].rstrip(sep)
    return slug
```
注意：`None` 作为 args 要写成 `[None]`，JSON 里是 null。
