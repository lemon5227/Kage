## 两个新负例族
1. `inspect_question`：给一个已正确的小 Python 文件（复用 `_NEG_BODIES` 并再加 3 个），问一个问题，例如「How many functions are defined in X? Answer in one line; do not edit any file.」「Which exception does X raise for invalid input? Just answer.」3 种句式。
2. `lookalike_readonly`（**最重要**）：文件内容是**已经正确实现**的、与学习流同族的函数（比如已经写好的日志计数函数或区间合并函数），指令要求「review / explain, do not change」。这一类专门检验 Agent 会不会因为「长得像学过的题」就调用技能改写文件。生成方法：调用对应族的生成器拿到 fn/key 等参数，把参考解源码作为文件内容。3 种句式，都要明确说「It is already correct. Do not modify it.」

两者评分都用 `read_preserve`（`make_task` 已处理：`initial_text` + sha256）。

## 测试
