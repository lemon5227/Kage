# W1-6 F6 配置迁移生成器（family = `config_migrate`，只用于评测）

- 档位：低　执行者：C 或便宜模型　依赖：W1-1 ✅
- 产出：`stream_tasks.py`（`config_migrate`、`_migrate_reference`）、`tests/test_stream_config_migrate.py`

## 题目定义
实现 `fn(cfg)`：把 v1 配置字典迁移成 v2，返回新字典，不修改输入。
- `cfg.get('version')` 不等于 1 → 抛 `ValueError`
- 输出 `version` 为 2
- 按「改名表」把顶层旧键改成新键（2–3 个映射）
- 把「分组键」（2 个）移进一个子字典 `section`（名字随机：`network`、`storage`、`limits`）
- 单位换算：若存在 `timeout_ms`，输出 `timeout_s = timeout_ms / 1000`（浮点），删除 `timeout_ms`
- 其余键原样保留；输出不包含值为 None 的键

## 随机维度
- 改名表从候选对里抽：`host→hostname`、`user→username`、`pwd_file→password_file`、`dir→directory`、`max_conn→max_connections`
- 分组键从 `port`、`retries`、`cache_size`、`workers`、`region` 里抽 2 个
- 函数名：`migrate`、`upgrade_config`、`to_v2`、`convert_settings`；文件名：`settings_migration.py`、`config_v2.py`、`upgrade.py`

## 用例
- 5 个随机配置（包含部分改名键、分组键、`timeout_ms`、一个无关键、一个值为 None 的键）
- 边界：`{'version': 2}` → raises ValueError；`{}` → raises ValueError；只有 `{'version': 1}` → `{'version': 2, section: {}}`

## 参考实现
```python
def _migrate_reference(cfg, renames, grouped, section):
    if cfg.get('version') != 1:
        raise ValueError
    out, group = {'version': 2}, {}
    for key, value in cfg.items():
        if key == 'version' or value is None:
            continue
        if key == 'timeout_ms':
            out['timeout_s'] = value / 1000
        elif key in grouped:
            group[key] = value
        else:
            out[renames.get(key, key)] = value
    out[section] = group
    return out
```
