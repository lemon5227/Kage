# W1-4 F4 CSV 清洗变换生成器（family = `csv_transform`）

- 产出：`stream_tasks.py`（`csv_transform`、`_csv_reference`）、`tests/test_stream_csv_transform.py`

## 题目定义
实现 `fn(text)`：输入是带表头的 CSV 文本，返回清洗后的 CSV 文本（也带表头）。依次执行：
1. 每个单元格去掉首尾空白；
2. 删除「必填列」为空的行；
3. 「邮箱列」转小写（若本题有邮箱列）；
4. 按「键列」去重，保留第一次出现的行；
5. 按「排序列」升序排序（字符串比较），稳定排序；
6. 输出用 `csv.writer(buf, lineterminator='\n')`，表头不变。

输入为空字符串或只有表头时，返回只有表头的文本（空字符串输入返回 `''`）。

## 随机维度
- 列集合从 `['id','name','email','city','team','score']` 里随机抽 3–5 列，保证包含键列；邮箱列 50% 概率存在
- 键列、必填列、排序列各自从已选列里抽（可以相同）
- 函数名：`clean_rows`、`tidy_csv`、`normalize_table`、`dedupe_export`；文件名：`export_clean.py`、`table_ops.py`、`crm_clean.py`
- 指令里用自然语言写清上面 6 步，并点名每一列的角色，并说明「use the csv module, '\n' line endings」

## 用例
- 5 个随机：3–9 行数据，含：首尾空格、必填列空值、大小写混杂的邮箱、重复键（含空格版本的重复）
- 边界：`''` → `''`；只有表头 → 原表头 + `\n`；含逗号的单元格（需要被引号包住，交给 csv 模块处理）

## 参考实现
```python
import csv, io
def _csv_reference(text, key, required, email, sort_col):
    if text == '':
        return ''
    rows = list(csv.reader(io.StringIO(text)))
    header, body = rows[0], rows[1:]
    idx = {name: i for i, name in enumerate(header)}
    out, seen = [], set()
    for row in body:
        row = [cell.strip() for cell in row]
        if not row[idx[required]]:
            continue
        if email:
            row[idx[email]] = row[idx[email]].lower()
        if row[idx[key]] in seen:
            continue
        seen.add(row[idx[key]])
        out.append(row)
    out.sort(key=lambda r: r[idx[sort_col]])
    buf = io.StringIO()
    writer = csv.writer(buf, lineterminator='\n')
    writer.writerow(header)
    writer.writerows(out)
    return buf.getvalue()
```
生成输入 CSV 时也用 `csv.writer(lineterminator='\n')` 写，再手工在部分单元格前后加空格（加在 writer 之前）。
