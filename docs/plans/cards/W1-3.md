- 产出：`stream_tasks.py`（`interval_merge`、`_interval_reference`）、`tests/test_stream_interval_merge.py`

## 题目定义
实现 `fn(intervals)`：输入是区间列表，返回合并后的区间列表，按开始时间升序。任何区间 start > end 抛 `ValueError`。不能修改输入。

## 随机维度（每个 seed 抽一组）
- 表示方式：`pair`（`[start, end]` 列表）或 `dict`（`{"start": s, "end": e}`，键名从 (`start`,`end`)、(`begin`,`finish`)、(`from`,`to`) 里抽）。输出用与输入相同的表示。
- 相接是否合并 `touching`：True 时 [1,3] 和 [3,5] 合并；False 时不合并（只有真正重叠 a.end > b.start 才合并）。
- 函数名：`merge_slots`、`combine_ranges`、`coalesce`、`merge_bookings`；文件名：`calendar_ops.py`、`ranges.py`、`booking.py`
- 指令必须写明：输入表示与键名、输出排序、相接规则（明说「touching intervals like [1,3] and [3,5] should/should not be merged」）、ValueError、不修改输入、保存文件。

## 用例
- 5 个随机：1–7 个区间，start 0–20，长度 0–6，打乱顺序
- 边界：`[]` → `[]`；一个 start>end 的区间 → raises ValueError；一组恰好相接的区间（用来区分 touching）；完全包含的区间（[1,10] 包含 [2,3]）

## 参考实现
```python
def _interval_reference(intervals, rep, keys, touching):
    pairs = [(iv[0], iv[1]) if rep == 'pair' else (iv[keys[0]], iv[keys[1]]) for iv in intervals]
    if any(s > e for s, e in pairs):
        raise ValueError
    merged = []
    for s, e in sorted(pairs):
        if merged and (s < merged[-1][1] or (touching and s == merged[-1][1])):
            merged[-1][1] = max(merged[-1][1], e)
        else:
            merged.append([s, e])
    return merged if rep == 'pair' else [{keys[0]: s, keys[1]: e} for s, e in merged]
```
