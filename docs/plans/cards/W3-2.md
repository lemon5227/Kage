## 策略规则（写死）
```python
def recover(error, history, checkpoints):
    goal = error.get('goal', '').lower()
    wants_write = any(w in goal for w in ('implement', 'fix', 'write', 'save', 'create', 'update'))
    if error.get('trigger') == 'finish_after_tool_error' and not error.get('written_files'):
        return {'action': 'request_help', 'reason': 'last tool failed and nothing was written'}
    if wants_write and not error.get('written_files'):
        return {'action': 'request_help', 'reason': 'task asks for a file change but none was made'}
    return {'action': 'stop'}
```
- 只用 `recover` 函数，标准库，不读写文件（会在沙箱里执行）。
- 接线：A5 学生的 `KageChainProvider` 传 `recovery_policy=RecoveryPolicy.from_bundle(<含该源码的 bundle>)`。bundle 的建法照 `tests/test_evolution_self_modify.py` 里的 `write_bundle`。
- `StreamLearner.step` 已经把 `help_requested` 当作需要教师（见 `row['help_requested']`），无需再改。
