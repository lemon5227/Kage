# W1-10 报告脚本 stream_report

- 档位：中　执行者：C 或中档模型　依赖：W2-1 ✅
- 先读：`core/evolution/stream.py`（`stream.jsonl`、`checkpoints.jsonl` 的字段）、`core/evolution/competence.py`（`help_log`）
- 产出：`scripts/experiments/stream_report.py`、`tests/test_stream_report.py`

## 用法
```
python scripts/experiments/stream_report.py --arm-dir A0=artifacts/e1/seed1/A0 --arm-dir A4=artifacts/e1/seed1/A4 ... --out artifacts/e1/report
```
可以给多个 seed 的同一臂（`A4=dir1 --arm-dir A4=dir2`），按实例合并。

## 输出
1. `report.md`：
   - 每臂每检查点：族内、跨族、负例通过率 `k/n`，加 Wilson 95% 区间；负例误用率
   - 配对比较：同一检查点、同一实例，A4 vs A0、A4 vs A1、A4 vs A3（以及有数据时 A5 vs A4、A6 vs A5、A6 vs A6-fixed）的 McNemar 精确检验 p 值（二项检验，b 与 c 为不一致对）
   - 学习流：每 10 个任务的学生独立成功率、教师调用次数、累计云费（从每臂 root 下的账本差额或 stream.jsonl 统计）
   - F1 旧能力保留：F1 在各检查点的通过率
   - 求教质量（A5/A6）：`help_log` 里事前求教的次数；精准率 = 事前求教的任务里「同族上一次学生独立失败」的比例（近似）；同时报告「没求教但学生失败」的次数（漏问）
2. `curves.png`：横轴检查点，纵轴族内成功率，每臂一条线 + 误差棒。用 matplotlib；沙箱没有 matplotlib 时跳过画图并在 report.md 写明。
3. `summary.json`：上述数字的机器可读版本。

## 公式（写死，不要自己发明）
- Wilson：`center=(p+z²/2n)/(1+z²/n)`，`half=z*sqrt(p(1-p)/n+z²/4n²)/(1+z²/n)`，z=1.96
- McNemar 精确：`p = min(1, 2*sum_{i<=min(b,c)} C(b+c,i) 0.5^(b+c))`

## 测试
- Wilson 与 McNemar 和手算值一致（给 3 组固定数字）
- 用两个小的假臂目录（手写 jsonl）生成报告，检查 report.md 包含关键行、summary.json 数字正确
- 缺某个检查点时不报错，标「无数据」
