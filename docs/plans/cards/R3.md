## Goal
Train a LoRA adapter on the R2 guidance-free samples and test whether the ability now lives in the weights:
the LoRA student gets NO skills, NO memory, NO lessons (arm A0 + adapter) and is compared with the plain A0
on the frozen eval sets, both evaluated 3 times in the same Kaggle session (GPU outputs vary run to run).

## 1. `scripts/experiments/r3_data.py` (new)
`python scripts/experiments/r3_data.py --sft FILE [--sft FILE ...] --out DIR [--cap 600] [--val-frac 0.1]`
- Inputs are `sft.jsonl` or `sft.jsonl.gz` files in the R2 row format (`task_id, family, negative, writes,
  tools, messages, target, source, attempt, guidance`).
- Refuse (exit non-zero with a clear message) if any row's family is a transfer family
  (`text_normalize`, `config_migrate`, `web_form`) or its seed (last `-` part of `task_id`) is not in the
  practice split (`core.evolution.stream_tasks.split_of(seed) == 'practice'`). These must never be trained on.
- Drop rows whose `messages` still contain guidance markers (`Lessons from earlier tasks`, `[tool call] `,
  `earlier page: pick the target_ref`) and count them (should be 0).
- Dedupe identical (messages, target) pairs; per-family cap `--cap` rows (keep a uniform random subset with a
  fixed seed so every family stays balanced; negatives are families too).
- Split train/val by `task_id` (hash-based, `--val-frac`), so all rows of one task stay on one side.
- Write `train.jsonl`, `val.jsonl`, `data-stats.json` (rows per family per split, dropped by reason, sha256 of
  both files).
