# G0 现场演示：不会 → 求教 → 学会 → 新题会（Mac 计算器，辅助功能接口）

```bash
KAGE_CTX=16384 python scripts/demo/g0_demo.py
```

约 3–4 分钟，本机起一个 4B 学生模型服务（结束即关），老师调用一次（DeepSeek 思考模式，约 $0.0004，经账本）。计算器在后台被操作，不抢键盘；你的“转换”模式和历史侧栏状态在每题后恢复。

1. **不会**：学生第一次做 (15 + 27) × 3，按 `15 + 27 × 3 =`，计算器按运算优先级显示 96。（学生有随机性，偶尔会做对，脚本最多试 3 次来展示失败。）
2. **求教**：老师看到失败的按键记录、检查器结果和计算器上实际有的按键，写一条通用规则（不含本题数字）。
3. **新题会**：学生没见过的 (9 + 6) × 4，规则放在任务旁，要求先写出“规则在这题怎么用”的计划再动手：`9 + 6 = × 4 =` → 60。

2026-10-24 实录（`evidence/reports/g0/demo/`）：第 1 步 96 做错；规则“先把括号部分算完按等号，再做剩下的运算”；第 3 步计划“先算 9 + 6 按等号得 15，再乘 4”，显示 60 做对。

**讲解要点**：规则放在系统提示里学生不用（3/15 = 无规则）；要它先把规则落到本题才会用（10/15）；全程通过辅助功能接口操作真实应用，检查器自己读计算器显示，学生说“做完了”不算。

**做演示时踩过的坑（已修）**：老师不思考时 3 次里 2 次建议按“括号键”（计算器没有）——改为给老师看可用按键 + 思考模式后 3/3 正确；学生误开历史侧栏会把以前的式子和答案放进观察——任务开始前关掉侧栏。
