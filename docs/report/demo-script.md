# 演示脚本（W6-4）

成片：[`docs/assets/demo/kage-demo.mp4`](../assets/demo/kage-demo.mp4)（83 秒，1600×1000）。生成方式：
`python scripts/demo/render_video.py --out <路径>`——运行 `scripts/demo/replay_demo.py` 回放真实记录（不启动模型），
按时间戳把终端输出渲染成画面，最后接成长曲线，由 ffmpeg 编码。不依赖录屏权限，换设备可原样重现。
直接在终端看：`python scripts/demo/replay_demo.py`。

目标：≤ 3 分钟，6 个镜头，每个镜头对应一次**真实运行**里的事件（数据：`evidence/kaggle/v10-results.tar.gz` → `e1/seed1/A6/`，E-2，A6 种子 1）。
录制方式：屏幕左边是终端，逐条回放该运行的 `stream.jsonl` / `evolution.jsonl`，并打开对应的模型轨迹；右边是 Kage 窗口里的消息气泡（交互层 `notices.py` 生成的三类消息）。旁白用中文或英文均可。

> 回放而不是现场跑：4B 学生每题 30–90 秒，现场跑会拖长且不可复现。回放的都是真实记录，屏幕上标注“回放：Kaggle v10 实录”。

| # | 镜头 | 屏幕上看到什么（数据位置） | 台词（约） |
|---|---|---|---|
| 1 | 说不会 | 第 1 题 `csv_transform-1000`：学生 5 步内没写对，外部检查不通过（stream.jsonl 第 1 行 `FAIL`）。气泡：“这个 CSV 整理我没做对，能请老师示范一次吗？” | “Kage 是本地 4B 小模型。第一次遇到 CSV 整理，它失败了，并且知道自己失败了。” |
| 2 | 求教 → 学会 | 教师（DeepSeek）从干净状态示范并通过；示范被提炼成参数化技能 `csv_tidy_transform_writer`，并由学生自己调用它重做本题通过才入库（之后的同类题还要在已见过的同类题上一起验证）；示范同时存入记忆（`learning.accepted=true, memory_stored=true`）。 | “老师的做法不是直接抄，而是变成一个带参数的技能，学生自己用它重做一遍通过了，才算学会。” |
| 3 | 后台自练 → 汇报 | 第 10 题后的后台轮 `e10`：智能体按自己的聚类选出最薄弱的两类（c0 CSV、c3 子集选择），各练 3 道新题，5/6 通过，能力估计 0.20→0.38、0.50→0.71（evolution.jsonl 第 1 行）。气泡：“空闲时练了 6 道题，CSV 整理 2/3、背包选择 3/3，已更新技能状态。” | “空闲的时候，它自己挑最没把握的题型练习，不花云费，然后告诉你练了什么、结果如何。” |
| 4 | 新题复用 | `interval_merge-*`：第一次失败求教学会 `interval_merge_writer` 后，之后两道新区间题直接调用技能一次通过（stream.jsonl index 19、20）。 | “再遇到同一类的新题，它直接用学会的技能，一步做完。” |
| 5 | 负例不误用 | `inspect_question` / `lookalike_readonly`（只读题，看起来像日志题）：相关性门控没有放出任何技能，学生只读不写，全部通过（stream.jsonl index 16、33、36；评测负例 24/24、误用 0）。 | “看起来像、但其实只需要回答问题的题，它不会乱用技能去改文件。” |
| 6 | 成长曲线 | `evidence/reports/e2-report/curves.png`：同类题通过率从 14/48（29%）到 45/48（94%）；未学过的题型上，知识不被注入（请求与原学生相同）。 | “60 道题、两个种子合计约 0.2 美元的教师花费，同类任务从 29% 到 90% 以上——这是一个会求教、会练习、知道边界的小模型。” |
